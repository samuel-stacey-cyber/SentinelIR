# SentinelIR - Shortlisted Research Questions

## 1. Log Information

How does combining HTTP access logs with application authentication logs affect SentinelIR’s detection of web authentication attacks compared with using HTTP access logs alone?

## 2. Response Guidance

To what extent does providing investigation and response guidance alongside SentinelIR alerts improve the appropriateness and completeness of response plans produced by cybersecurity students?

## 3. Combined Detection and Guidance

How effectively does SentinelIR detect selected web attacks and provide technically appropriate investigation and response guidance in a controlled environment?

# Potential Sub-Questions

## 1. Detection Thresholds

How do detection thresholds affect the trade-off between missed attacks and false alerts for selected web attacks under varying levels of benign activity?

## 2. Enumeration and False Alerts

To what extent can request rate, path diversity and response-code patterns help SentinelIR distinguish directory enumeration from normal browsing in a controlled web environment?

## 3. Temporal Detection Rules

To what extent does incorporating event order and time windows improve the precision and recall of SentinelIR’s web authentication-attack detection compared with count-based rules?

## 4. Comparison with an Existing Tool

How does SentinelIR’s detection of selected web attack behaviours compare with a suitable existing log-analysis tool when evaluated against the same controlled activity and ground truth?
