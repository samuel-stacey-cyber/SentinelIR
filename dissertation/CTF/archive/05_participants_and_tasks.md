### 2. Comparison design

- Needed: `Before CW2 submission`
- Question: Will each participant complete both conditions or only one?
- Options / trade-offs: Within-participant matched tasks / separate groups
- My recommendation: Consider both conditions with different matched scenarios when recruitment is limited. Counterbalance order and scenario-condition assignment; avoid repeating the same incident. Separate groups reduce carryover but usually need more recruits. Confirm the trade-off before locking the design.
