# SentinelIR — CTF proposal

I want to build a fictional company portal where students work through a short CTF while SentinelIR collects and analyses the logs in the background.

The core route has three flags: access a weak account, follow clues to a second account, then interpret an internal audit report. Two optional challenges give more experienced participants something harder to attempt.

CTF development has not started. The route is agreed as my current direction, but hosting, implementation and study arrangements are still open to feedback. SentinelIR remains CLI-only; the website is separate.
